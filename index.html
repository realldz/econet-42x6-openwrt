Kernel modules for the Econet vGP-42X6V1

OpenWrt's airoha/en7523 target is source-only, so no kmods/ directory is published for this board and a kernel module cannot be installed from downloads.openwrt.org. This branch carries a repository per release instead. Userspace packages are unaffected: they come from the generic aarch64_cortex-a53 feeds as usual.

No release has been published yet. This page is a placeholder that the first release overwrites. Until then there is nothing here to point apk at.
