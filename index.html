Packages for the Econet vGP-42X6V1

OpenWrt's airoha/en7523 target is source-only, so OpenWrt publishes no package feed for this board and a kernel module cannot be installed from downloads.openwrt.org. This branch carries a repository per release instead, holding the target's own packages and the kernel modules built against that release's kernel. Userspace packages are unaffected: they come from the generic arm_cortex-a7 feeds as usual.

releases.json lists every published release with its kernel and the sha256 of its images.

Most recently built: v0.1.2-m2.

A module only loads into the kernel it was built against. Match the release tag in the URL to the image you are running.
